# 连续二面角条件分布：数据规范与 v2 思路

## 0. 思路

对 `p(φ,ψ | m_{i-1}, m_i, m_{i+1})`，**不再从 72×72 计数直方图出发**，而是用原始 cos/sin 直接做环面连续核密度估计，得到**循环、平滑、处处 > 0、简单禁区/峰区**的分布；产物是 8000 个上下文的可 mmap 数组 + 特征点表，200 字节内可查询任意角度。

链路：`PBD_PATH/*.pdb` → `pdbextract.exe` → `segments.jsonl`（连续角）→ `build_v2.py` → `result/v2/`。

## 1. 数据规范

### 1.1 来源与链路

| 环节 | 位置 | 说明 |
|---|---|---|

| 提取器 | `src/date/pdbextract.exe` | 读 `pbd_config.json`（`PBD_PATH` / `BIN_PATH` / `NUM`） |
| 连续数据 | `datebase/round_bin/segments.jsonl` | 一行一段，含逐残基 cos/sin |

> `datebase/date_init/*.bin + manifest.tsv` 是**上一版**产物，格式不同（见 1.6），**不要用**。

### 1.2 提取规则（`src/date/README.md` 即规范）

1. 只读第一个 `MODEL`（无 MODEL 记录读全文）——NMR 多模型不会重复计数。
2. 残基白名单 = 20 种标准氨基酸；`MSE` 保留并记作 `M`；水/配体忽略。
3. 遇到以下情况**切段**：非标准残基、`TER`、链切换、缺 N/CA/C 任一主链原子、相邻残基 `C–N` 距离 > `BREAK_DIST`(2.5 Å)。
4. 段长 < `MIN_LEN`(3) 整段丢弃。
5. 二面角只算 φ、ψ，存 cos/sin（6 位小数）。

### 1.3 角度定义与哨兵

- **φ = C(i−1)-N-CA-C**，**ψ = N-CA-C-N(i+1)**；符号与 Biopython/PyMOL 一致（α 螺旋 φ≈−60°、ψ≈−45°），**不做符号翻转**。
- 端点角不存在：`cos_phi[0]=sin_phi[0]=0`、`cos_psi[n−1]=sin_psi[n−1]=0`。
- 这两个 `(0,0)` 哨兵经 `atan2(0,0)=0` 会变成**假角度 0°**，所以任何统计都必须**跳过 i=0 和 i=n−1**。

### 1.4 三元组样本定义

对每个 segment 的 `i ∈ [1, n−2]`：

```
sample = ( m_{i-1}, m_i, m_{i+1}, φ_i, ψ_i )
```

即**只用中心残基自己的 φ、ψ**，标签取左右邻。每段贡献 `n−2` 个样本，共 8000 个上下文，索引：

```
idx = (a*20 + b)*20 + c      a,b,c ∈ [0,20) 对应 ACDEFGHIKLMNPQRSTVWY
```

### 1.6 两个必须知道的数（避免用错）

1. **`result_.txt` 里的 8,277,496 是旧数**，来自 `date_init`（8,408,870 残基、65,687 行、含 `model≠1` 的 10,292 行/775,523 残基；8,408,870 − 2×65,687 = 8,277,496）。当前 `triplet_probs.npy` 用的是 **7,545,294**。
2. **旧 `.bin` 格式**：`int32 头(n) + n×17 字节`（1 字节 AA + 4×float32: cosφ,sinφ,cosψ,sinψ），哨兵是 **NaN 不是 0**，且没有 seq。与当前 jsonl 不兼容。

### 1.7 已知偏置

- **有序化偏置**：只保留主链完整、无断链的残基，无序区/柔性区系统性缺席 → 数据里的"禁区"比真实分布更空。
- `MSE→M` 把非标准残基当标准用（量小，但严格说是污染）。

## 2. 当前思路（v2）

### 2.1 需求与取舍

| 需求 | v2 的做法 |
|---|---|
| 0. 简单禁区和峰区 | 阈值把环面切成两区：禁区取小正地板，峰区保留平滑密度 |
| 1. 循环且平滑 | 双线性撒点 + FFT 圆周高斯（周期天然；阈值前 \(C^\infty\)） |
| 2. 抛弃离群小成分 | 平滑后连通分量，质量 < 0.5% 的孤立岛丢弃 |
| 3. 任意点 > 0，禁区不为 0 | 加 1% 均匀地板，禁区值 = ε/72² ≈ **1.93e-6** |
| 4. 数据友好 | mmap float32 + 极简 reader + 双线性插值 |

三条硬约束是**构造出来的**，不靠调参：周期由 FFT 卷积保证，可导由高斯核保证，正性由地板保证。

### 2.2 模型

$$
p(\phi,\psi)= (1-\varepsilon)\,\tilde p_{\text{peak}}(\phi,\psi) + \varepsilon\,u(\phi,\psi),
\qquad u\equiv\frac{1}{72^2},\quad \varepsilon=0.01
$$

**估计步骤**（每个上下文 `(a,b,c)` 独立）：

1. **连续撒点**：把该上下文的原始 `(φ,ψ)` 以双线性权重撒到 72×72 环面栅格。这是首阶分箱，**不是计数直方图**——每个点按小数坐标分摊到 4 格，避免 bin 边界锯齿。
2. **圆周平滑**：FFT 卷积各向同性高斯，`σ = 2.5 格 = 12.5°`；`clip(·,0)` 后归一。
3. **禁区阈值**：`thr = max(2% × 峰值, 1e-6)`。低于 `thr` 的格子判为禁区。
4. **离群丢弃**：在 `g > thr` 上做 4-连通（环面 wrap）分量，质量 < 0.5% 且累计丢弃 < 5% 的分量置零——即"刻意维护的特殊构型"。
5. **峰区归一 + 地板**：`p_peak` 归一，`p = (1-ε)p_peak + εu`；若峰区为空则退化为均匀（保证 Σ=1）。

### 2.3 特征点

- 取 `p_peak` 的**所有**局部极大（8 邻域严格大于）；
- 阈值 `≥ 1.2% × 峰值`（相对阈值，避免小 n 把阈值顶爆炸）；
- **非极大抑制 2 格（10°）**：10° 内多个极大合并为一个特征，防止把同一峰的起伏重复标；
- 每上下文最多 16 个。

实测：**均值 4.36 / 中位 4 / 最大 16**；全库 34,864 个特征点，**0 个落在禁区**。

### 2.4 参数

| 参数 | 值 | 含义 |
|---|---|---|
| `NB` / `BW` | 72 / 5° | 栅格分辨率 |
| `SIGMA` | 2.5 格 | 圆周高斯宽度（12.5°） |
| `FORB_REL` | 0.02 | 禁区阈值 = 2% 峰高（相对） |
| `DROP_MASS` / `DROP_CAP` | 0.005 / 0.05 | 分量丢弃阈值 / 安全阀 |
| `FLOOR_EPS` | 0.01 | 地板总质量 |
| `PEAK_MIN_FRAC` / `NMS_DIST` | 0.012 / 2.0 格 | 特征点阈值 / 合并半径 |
| `MAX_PEAKS` | 16 | 特征点上限 |

### 2.6 验证

**单元核对**：Σ=1（min=max=1.000）；全 grid 最小值 = 1.93e-6 = 地板；最大值 0.020。

**位置正确性**：模型 argmax 与经验 argmax 相差 **5–10°**（≤2 格）。

| 上下文 | 经验 argmax | 特征数 | 符合预期 |
|---|---|---|---|
| A-A-A | (−62.5,−42.5) | 3 | α + β |
| G-G-G | (+77.5,+17.5) | 8 | 左手 α 为最大区，另有 α/β |
| P-P-P | (−67.5,+152.5) | 2 | PPII |
| V-V-V | (−117.5,+127.5) | 3 | β |
| L-L-L | (−62.5,−42.5) | 2 | α |

**禁区与经验的一致性**（20 张对照组，含 5 个基准 + 15 个随机 n≥300）：

| 指标 | 范围 | 含义 |
|---|---|---|
| 经验质量落在禁区 | 0.0%–8.2%（均值 ~3%） | 禁区基本没吃掉真数据 |
| 禁区格中经验为 0 的比例 | 94%–100% | 禁区确实落在空格上 |
| 禁区占比 | 81.5%（中位） | 与 Ramachandran 允许区量级一致 |

> 8.2% 的最高值出现在 A-A-A，是 2% 阈值切掉 α 峰尾巴所致，不是错位；把 `FORB_REL` 降到 0.01 可放宽。

### 2.7 分辨率地板与限制

- **每上下文 n 中位 714**，核内平均点数：h=7.5° → 1.0 个，h=15° → 3.9 个，h=30° → 15.6 个。**单上下文可分辨尺度约 25–30°**；7.5° 的"峰"是噪声量级。
- 因此 v2 抓到的是 α/β/PPII/左手 α 这一尺度（20–30°）的**主形态**，不是窄峰字典。
- v2 **没有**做显著性与自举；特征点是描述量，不是"统计显著峰"。
- C / W 的稀疏上下文（n<100）本质不可靠，v2 只是给了个平滑先验，不能当结论。
- 平滑是各向同性固定带宽：**脊（β 带沿对角线）会被抹成一条胖区**，没有单独建模；这是下一步的事。
- 读取端（v2.1）：峰区双三次（C¹），边界带用 δ；**禁区不可导是设计选择，不是缺陷**。

### 2.8 读取接口 v2.1（软约束接入）

v2.1 **只改读取端**（`src/v2/p_v2.py`），`result/v2/` 的数据一个字节没动。

| 方法 | 返回 | 用途 |
|---|---|---|
| `p(φ,ψ,a,b,c)` | 格点质量（Σ=1） | 概率、能量积分 |
| `p_density(...)` | 质量 / ΔA | 需要真密度时 |
| `grad(...)` | `(p, ∂p/∂φ, ∂p/∂ψ, ∇log p)`，单位每度；边界带返回 `None` | 峰区梯度 |
| `delta(...)` | 有符号距离（度），允许区 >0 | 余量、边界反射 |
| `is_forbidden(...)` | bool | 格点合法性 |
| `marginal(ctx, axis)` | 72 向量 | 端点一维边缘 |

**三条约定（必须与链模型一致）**

1. **数值是格点质量，不是密度。** `Σ p = 1`；密度 = `p / ΔA`，ΔA=(5°)²=7.6154e-3 rad²，系数 131.31。
2. **合法集直接用 `forbidden.npy`，不另设 τ。** p 在边界有 ~83× 跳变，任何落在跳变区间的 τ 给出同一集合。
3. **峰区梯度只在 interior（4×4 模板全在允许区）内有效**；边界 2 格内用 `delta()`。`grad()` 返回 `None` 就是"改用 δ"。

**为什么只做峰部可导**：链模型的积分与采样被指示函数限制在允许区，边界由 δ 表示，禁区不可导不影响判定。禁区占 84% 的环面，任何"全域对 −log p 求梯度"的惩罚法都会在平区失去方向。

**实测（`p_v2.py` 自检输出）**

| 项 | 结果 |
|---|---|
| 双三次 vs 双线性 | 中位 0.7%，p95 2.5%，max 3.5% |
| 梯度 vs 有限差分 | 相对 2e-5 |
| 跨格梯度跳变 | ~1e-4 |
| δ 的 Lipschitz 比 | ≤1.08（chamfer 各向异性） |
| 边缘 Σ | 1.000000 |
| 查询耗时 | p 13 µs / grad 9 µs / delta 9 µs |

**已知边界情况**

- P 类上下文允许区窄，interior 只占 3–9% 的格子，`grad()` 经常返回 `None`，退化为纯 δ 路线。
- 抽样 160 个上下文：interior 覆盖中位 8.7%，最小 3.4%，无空集。
- 端点边缘默认按均匀 π 加权；要用数据背景频率就传入 `pi`。
- `peaks.jsonl` 报的是格心，`p()` 的节点在整数坐标，两者差 2.5°；只影响对照与初值报告，不影响查询。

## 3. 复现

```powershell
$py = "src\process_Statistics\.venv\Scripts\python.exe"

& $py src\v2\build_v2.py      # 解析 segments.jsonl -> 建模 -> result/v2/*.npy
& $py src\v2\plot_v2.py       # 500 张评估图 -> result/v2/imgs
& $py src\v2\compare_v2.py    # 20 张经验对照 -> result/v2/compare
& $py src\v2\p_v2.py          # 读取自检
```

`p_v2.py` 的自检会打印：基本取值、梯度 vs 有限差分、δ 的符号与范围、端点边缘的 Σ。

- 改禁区松紧：`FORB_REL`
- 改平滑：`SIGMA`
- 改地板：`FLOOR_EPS`
- 改特征点：`PEAK_MIN_FRAC` / `NMS_DIST`
- 改完重跑 `build_v2.py`（更新 peaks.jsonl）再 `plot_v2.py`。
