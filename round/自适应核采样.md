# 二维 von Mises 自适应核密度估计：思路与流程

## 核心动机

放弃 DP 混合与 MCMC，根本原因是 von Mises sine 成分的**形状约束是硬伤**：无论混合层放多少个单峰成分，单个成分的尾部行为与曲率都被 Bessel 归一化常数锁死，异形脊状或弯曲主形态只能靠成分堆叠勉强逼近，后验密度出现串珠伪影。你的目标已降为“拟合主分布形态、不追求整体峰拟合”，因此换框架的代价可以接受。

二维 von Mises 自适应核密度估计（AKDE）是 Ramachandran 密度估计中**已被验证的工程方案**。Shapovalov & Dunbrack 用该方法构建 backbone-dependent rotamer library，专门处理蛋白质 `(φ, ψ)` 角度分布的非规则、多峰与局部密度差异大的问题。核方法不假设成分单峰，叠加后的密度形态完全由数据驱动。

## 方法定位

与原有框架的根本区别：

|  | 原框架（vM sine DP 混合） | 新框架（vM AKDE） |
| --- | --- | --- |
| 成分形状 | 受 Bessel 常数约束，尾部固定 | 由数据局部密度自适应调节 |
| 多峰来源 | 混合层承担 | 核叠加自然形成 |
| 推断方式 | MCMC 后验采样 | 确定性计算，无需采样 |
| 计算成本 | 两链各 6000 次 MCMC | 网格逐点求和，一次完成 |
| 异形适应 | 差（成分形状硬约束） | 好（自适应带宽跟随局部密度） |

## 数学模型

### 基础形式：二维 von Mises 核

对于 `N` 个角度对 `{(φ_i, ψ_i)}_{i=1}^N`，在查询点 `(φ, ψ)` 处的密度估计为：

\[
\hat{p}(\phi,\psi)=\frac{1}{4\pi^2 N}\sum_{i=1}^{N}\frac{1}{[I_0(\kappa/\lambda_i)]^2}\exp\left\{\frac{\kappa}{\lambda_i}\big(\cos(\phi-\phi_i)+\cos(\psi-\psi_i)\big)\right\}
\]

其中 `κ` 是基础浓度参数（带宽的倒数），`λ_i` 是第 `i` 个数据点的**局部自适应因子**，`I_0` 是零阶修正 Bessel 函数。

这个形式假设 `φ` 与 `ψ` 在核内可分离，对于“抓住主分布形态”的目标足够；若主形态呈现强对角耦合，可改用完整的 bivariate von Mises sine 核，但会引入额外的交叉项参数，增加带宽选择复杂度。建议先跑可分离版本，诊断残差后再决定是否升级。

### 自适应带宽机制

`λ_i` 的核心逻辑：**高密度区核变窄，低密度区核变宽**。

\[
\lambda_i = \left(\frac{\prod_{j=1}^{N}\hat{f}_{\text{pilot}}(\phi_j,\psi_j)}{\hat{f}_{\text{pilot}}(\phi_i,\psi_i)}\right)^{1/2}
\]

其中 `\hat{f}_{\text{pilot}}` 是 pilot 密度估计，通常用**固定带宽**的普通 KDE 得到。这个平方根规则来自 Abramson (1982)，在 Dunbrack 的 AKDE 实现中被直接采用。

**作用机制**：
- 主峰区域 `\hat{f}_{\text{pilot}}` 大 → `λ_i` 小 → 等效浓度 `κ/λ_i` 大 → 核窄 → 保留峰形细节；
- 稀疏区域或离群点 `\hat{f}_{\text{pilot}}` 小 → `λ_i` 大 → 核宽 → 抑制伪峰，避免离群点拉出虚假结构。

这正好解决你“异形分布拟合差”的问题：原框架中单峰成分无法跟随主形态的弯曲或拉长，而 AKDE 让每个数据点周围的核宽度随局部密度调整，主形态的脊线区域被密集窄核覆盖，形态自然被追踪。

## 实施流程

### 第一步：数据准备

角度对 `(φ_i, ψ_i) ∈ (-π, π]²`，转成弧度制。无需转单位向量，AKDE 直接在角度坐标上计算。保留你现有的数据清洗步骤。

### 第二步：Pilot 密度估计

用**固定带宽**的二维 von Mises KDE 计算 `\hat{f}_{\text{pilot}}`：

\[
\hat{f}_{\text{pilot}}(\phi,\psi)=\frac{1}{4\pi^2 N}\sum_{i=1}^{N}\frac{1}{[I_0(\kappa_0)]^2}\exp\{\kappa_0(\cos(\phi-\phi_i)+\cos(\psi-\psi_i))\}
\]

`κ_0` 的选择：可用留一交叉验证最大化对数似然，或参考 Dunbrack 的实践取一个适中的基础值。**不需要**在这里追求最优带宽，pilot 只用于计算 `λ_i` 的相对大小。

### 第三步：计算自适应因子

在**每个数据点** `(φ_i, ψ_i)` 处取 pilot 密度值，按平方根规则计算 `λ_i`。注意归一化分母（几何均值）使 `λ_i` 的典型值在 1 附近，`κ/λ_i` 的实际范围由数据密度对比度决定。

### 第四步：在网格上计算 AKDE

在 `360 × 360` 网格上逐点计算最终的 `\hat{p}(\phi, \psi)`。每个网格点需要对全部 `N` 个数据点求和。计算量约为 `360 × 360 × N` 次指数运算。若 `N` 在数千到数万量级，单机可在分钟级完成。若 `N` 很大，可先做空间分箱加速，但建议先跑全量确认效果。

### 第五步：带宽调优（可选）

基础 `κ` 的选择影响平滑程度。Dunbrack 的做法是：用交叉验证在 `κ` 的候选值上最大化留一对数似然，同时比较 AKDE 与固定带宽 KDE 的验证性能。你的目标不是精确概率，可以取一个使主形态清晰、不出现碎片伪峰的 `κ` 即可。实操建议：从 `κ = 50~200` 范围试几个值，目视检查 340° 附近的典型 Ramachandran 主峰是否连贯。

## 与原流程的对应关系

| 原步骤 | 新流程中的处理 |
|---|---|
| 先验设定（H1, H2, DP 质量参数） | **全部删除** |
| 初始化聚类 | **全部删除** |
| Auxiliary Gibbs 聚类 | **全部删除** |
| 均值拒绝采样 | **全部删除** |
| 精度 Wishart 采样 | **全部删除** |
| 后验样本平均（式 7） | 替换为 pilot + AKDE 的确定性两步计算 |
| 360×360 网格密度估计 | **保留**，改为逐点 AKDE 求和 |
| 线性插值平滑 | **保留** |

## 预期效果与局限

**预期**：主分布形态（α 区、β 区、left-handed 区等）的边界与脊线会被更准确地追踪。异形区域（如 β 区向 α 区的桥接带、非标准 Ramachandran 区域）不再被单峰成分的形状约束抹平或扭曲。低密度区域的离群点不会产生虚假峰。

**局限**：
- 可分离核假设 `φ` 与 `ψ` 在核内独立，若主形态存在强对角耦合（如某些非标准氨基酸的拉长对角分布），核形状会略微失真。若诊断发现此问题，可将核替换为完整的 bivariate vM sine 形式，但 `λ_i` 的调节机制不变。
- 没有不确定性量化。你的目标不需要后验样本，但如果后续需要置信带，AKDE 本身不提供贝叶斯不确定性。
- 带宽 `κ` 的选择需要一次调参，但比 MCMC 的收敛诊断简单得多。
