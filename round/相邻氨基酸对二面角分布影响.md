# 相邻氨基酸对二面角分布的影响

## 1. 数据与方法

- 数据源：`result/static/triplet_probs.npy`，8000 个三元组 `(m_{i-1}, m_i, m_{i+1})` 的 72×72 经验直方图（5° 分箱）；
- 平滑：σ=1.5 格的环面高斯卷积；
- 度量：JS 散度、熵、峰位偏移、共享峰覆盖率、边缘吞峰率；
- 权重用“非零格数”作为样本量代理。

## 2. 邻居到底贡献多少信息

| 量 | 数值 |
|---|---|
| 总体二面角熵 H₀ | 6.546 nats |
| 已知中心残基 H(center) | 6.332 nats |
| 已知左邻 H(center,left) | 6.276 nats |
| 已知右邻 H(center,right) | 6.236 nats |
| 已知完整三元组 H(triplet) | 5.989 nats |

- 中心残基身份：**0.214 nats（0.31 bit）**；
- 左邻（给定中心）：**0.056 nats**，占剩余熵 0.89%；
- 右邻（给定中心）：**0.096 nats**，占剩余熵 1.52%；
- 左右合起来：**0.343 nats（0.50 bit）**，占剩余熵 **5.4%**。

结论：**右邻比左邻重要约 1.7 倍**；且左右联合（0.343）明显大于各自之和（0.152），多出的约 0.19 nats 是**左右协同**，必须按三元组成对建模。

## 3. 具体结构效应

- **脯氨酸在 i+1**：对全部 20 种中心残基都是最强右邻（JS 0.11–0.25）。区域质量从 α 0.433→0.098、β 0.243→0.382、PPII 0.11→0.292——P 的 φ 被锁在 −60° 附近，逼着前一个残基走伸展构象。
- **脯氨酸在 i−1**：影响温和（α 0.401、β 0.206、PPII 0.142）。
- **甘氨酸**：作中心时熵最高（7.28），左手 α 质量 0.163（总体 0.02）；作左邻时 β 升到 0.285。
- **β-支链（V/I/T）在 i−1**：β 0.301（总体 0.243）。
- **中心残基敏感度**：C/H/W/N/G 最敏感（JS 0.073–0.095），V/I/L/P 最稳（0.039–0.045）。

## 4. 峰位与共享峰

- 每个中心残基有 3–12 个共享峰（P 3、A 5、V 7、G 6、C 11、H 12）；
- 匹配上的峰，位置偏移中位 0–5°、90 分位 10°、全部 ≤15°——**小偏移是常态**；
- 共享峰对上下文峰质量的覆盖率：V 0.95、P 0.94、A/I 0.91、L 0.90；G 仅 0.64、N 0.79、H 0.80、C 0.82；
- 边缘化（叠加 400 个上下文）会把峰合并：吞峰率 P 7%、A 10%、G/C 44%——这就是“同一残基不同上下文平均后峰降成高原”的来源。

## 5. 建模含义

- 峰位固定 + 只调权重，对 A/I/L/P/V 够用；对 G/C/H/N/D/W 会漏掉 16–36% 的峰质量，需要加峰、分家族，或允许小的位置偏移（δ ≤ 2 格）；
- 基底用“经验边缘直方图 + 圆周高斯平滑”即可，不需要样条/马尔可夫；但基底必须去峰，避免与峰重复计数；
- 条件只需保留到两个邻居（三元组），更远的邻居/三级环境体现在异类与残差里。
