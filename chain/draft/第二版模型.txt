

一,简化模型符号约定
存在一条n个氨基酸序列,抽象为一条链式连杆
方向c端到n端

只描述羧基C L_{i,c}-氨基N L_{i,n}
符号约定,第i个氨基酸N_i结构
刚体氨基酸为一个关节N_i表示,自由度2,q_{i,ψ}q_{i,φ}

肽键转角关节为J_i,自由度1,q_{ω}

φ_i：轴 = N_i–Cα_i 键；键上原子 N_i、Cα_i 不动，远端的 Cα 侧连同 C_i 及全部下游绕轴转动。
ψ_i：轴 = Cα_i–C_i 键；Cα、C 不动，N_{i+1} 及下游转动。
ω_i：轴 = C_i–N_{i+1} 肽键；C、N 不动，Cα_{i+1} 及下游转动。

封装氨基酸刚体L_i,自由度2,q_{i,ψ}q_{i,φ},且包含一个标签M∈[m_1,....,m_20]

完整n氨基酸链式结构,包含3n-1自由度

只做相邻符合位阻的二面角约束
对空间做重叠判断,近似为节点连接,存在半径为Ω的圆筒空间做判断

完整式: B = (L_{1,c} -> N_1 -> L_{1,n}) -> J_1 ->....-> J_n-1-> (L_{n,c} -> N_n -> L_{n,n}) 结构式
	M = ( M_1 -> ... -> M_n)标签式

简化式: B = L_1 -> J_1 ->....-> J_n-1 -> L_n
	M = ( M_1 -> ... -> M_n)标签式




二,简化约束
1.概率统计代替位阻的约束,二面角存在潜在分布关系
P(φ(i),ψ(i)|m_i-1,m_i,m_i+1)
且概率代替能量
2.概率统计代替ω分布,直接映射到0或180
ω(i)={[0,180] | ω∈(m_i ,m_i+1)}
故已知序列默认ω全部已知

三,问题阐述
现在存三条序列 B = B_i -> B_n -> B_m
其中仅B_i,B_m知道全部自由度和绝对空间参数,和标签式
B_n仅知道包含i个氨基酸标签式列表

现暂不考虑B_i,B_m完整空间位阻

设B_i  n端L位姿 T_0 ,B_m c端位姿T_i+1
B_n 合法组合 Q_n,B合法组合 Q

先试评估
1.判断B_n Q中是否存在q使得L_1,L_n能达到T_0,T_i+1的绝对空间位置?不考虑对接
2.判断B_n Q中是否存在q使得 B = B_i -> B_n -> B_m合法?
3.假设存在Q_n,B = B_i -> B_n -> B_m合法,试使用一个多维参数,其值来评估是否B_n序列对于上下文的稳定程度,即表示松弛和紧绷两个信息
4.整合,试着使用一个多维参数,同时包含序列不合法 - 序列合法紧绷程度,合法和稳定程度整合到同一个信息空间
